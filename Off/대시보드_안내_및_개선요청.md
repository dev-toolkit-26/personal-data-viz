# Off-Trade 대시보드 — 기능 안내 및 개선사항 요청

안녕하세요. Off팀에서 사용하실 **Off-Trade 영업 대시보드** 프로토타입을 공유드립니다.
실제 데이터(채널/거래처/SKU/실적)가 들어간 상태이니, 직접 클릭해 보시면서 **개선했으면 하는 점**을 자유롭게 적어 회신 부탁드립니다.

---

## 0. 열어보는 방법

1. 첨부된 `index-standalone.html` 파일을 더블클릭 → 웹브라우저(크롬 권장)로 열립니다.
2. 비밀번호 입력창에 **`1111`** 입력 → 들어가집니다.
   - ※ 이 파일은 검토용입니다. 차트/표 라이브러리 로딩을 위해 **인터넷 연결**이 필요합니다.
   - ※ 검토용이라 데이터 저장(Supabase) 기능은 동작하지 않을 수 있습니다. 화면/기능만 봐주시면 됩니다.

---

## 1. 대시보드 개요

26년 Off-Trade 영업 현황을 **AP(연간계획) · RoFo(롤링 포캐스트) · FCST(예측) · Actual(실적) · 2025년(전년)** 기준으로 비교/추적하는 대시보드입니다.
상단 9개 탭으로 구성되어 있습니다.

| 탭 | 내용 |
|----|------|
| **FCST Status** | 당월 예측 대비 실적 현황 (메인 화면) |
| **YTD** | 연초 누적(Year-to-Date) 채널별 달성 현황 |
| **Minutes** | 채널별 회의록 작성/보관 |
| **Revenue** | 지점별 Net Revenue (AP Target vs 실적) |
| **SKU Detail** | 채널 ▸ 거래처 ▸ SKU 상세 실적 |
| **SKU History** | SKU 월별 추이 + 25 vs 26 YoY 비교 |
| **Order Pattern** | 주간/일간 발주 추이 |
| **Calendar & To-Do** | 일정 + 할 일 관리 |
| **Data Update** | 파일 업로드로 데이터 갱신 |

---

## 2. 탭별 주요 기능

### ① FCST Status (메인)
- **월간 추이 차트** — RoFo / Actual / FCST(당월) / 2025년 비교 (HL)
- **FCST Summary 표** — 채널 ▸ 거래처 단위 집계
- **SKU 주간 FCST 누적** — W1~W5 주차 누적, 전월(LM)·전년(LY) 대비. 브랜드 클릭 시 하위 SKU 펼침

### ② YTD
- 채널별 YTD(연초 누적) **AP / RoFo / Actual / 2025** 비교
- **메인 KPI: Actual / AP 달성률(%)**
- 전체 월간 추이 + 채널 ▸ 거래처 표

### ③ Minutes (회의록)
- 채널별(전체/CVS/HYPER/SM/C&C/ALSM) 회의록 작성
- 서식 편집(제목·굵게·색상·정렬), 카드/이미지/Action Items 추가

### ④ Revenue
- 지점별 YTD Net Revenue 달성률, 월별 AP Target vs 실적
- **P&L Detail** — 전 지점 손익 항목 비교 (기간 선택)

### ⑤ SKU Detail
- 채널/거래처/브랜드/월 필터로 SKU별 상세 실적 조회

### ⑥ SKU History
- SKU 월별 히스토리(’25.1 ~ ’26.2), HL ↔ QTY 단위 토글
- **기간별 ’25 vs ’26 비교 (SKU별 YoY)**

### ⑦ Order Pattern
- 주간 발주 추이, 채널별·거래처별 일간 발주 상세

### ⑧ Calendar & To-Do
- 일정 등록/편집(반복 설정 가능), 할 일 관리(중요도·기한별 분류)

### ⑨ Data Update (데이터 갱신)
파일 업로드만으로 데이터가 갱신됩니다.
- **① RoFo Update** — 통합본(월·분기) 업로드 → AP·RoFo·25년 기준 갱신
- **② FCST Update** — 매주, 영업담당 22개 파일 일괄 업로드 → 주차(W1~W5) 합산
- **③ DSR (Actual)** — 일별 실적 원본 → 채널/거래처/SKU/월별 HL·수량·매출 집계 (25/26년 자동 감지)
- **④ Revenue Excel** — Segment별 매출예산/실적 → P&L 자동 반영

### 주요 용어
AP(연간계획) · RoFo(롤링 포캐스트) · FCST(예측) · DSR(일별 실적) · Actual(실적) · LM(전월) · LY(전년) · YTD(연초누적) · YoY(전년대비) · HL(헥토리터) · NSV(순매출) · W1~W5(주차)
채널: CVS(편의점) · HYPER(대형마트) · SM(슈퍼마켓) · C&C(창고형) · ALSM · UNION

## 3. 개선사항 요청 🙏

아래 항목을 참고하여 **자유롭게** 의견 주시면 반영하겠습니다. (정답 없습니다)

**A. 화면 구성 / 가독성**
- 보기 불편하거나 너무 복잡한 탭/표/차트가 있나요?
- 추가로 한눈에 보고 싶은 지표(차트·요약)가 있나요?

**B. 데이터 / 지표**
- 빠진 채널·거래처·SKU·기간이 있나요?
- 비교 기준(AP/RoFo/FCST/전년 등)이 실제 업무와 맞나요? 더 필요한 비교가 있나요?

**C. 업무 활용도**
- 실제 업무에서 가장 자주 볼 화면은 무엇인가요? (그 화면을 메인/상단으로 배치)
- 현재 엑셀/수작업으로 하는 것 중 이 대시보드로 대체하고 싶은 것이 있나요?

**D. 기능 제안**
- 필터, 다운로드/엑셀 내보내기, 알림 등 추가로 필요한 기능이 있나요?

**E. 오류 / 이상**
- 숫자가 틀리거나, 클릭이 안 되거나, 화면이 깨지는 곳이 있으면 **탭 이름 + 위치**와 함께 알려주세요. (가능하면 화면 캡처 첨부)
