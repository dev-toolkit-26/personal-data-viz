# On-Trade 운송비 분석 시트 — Claude Code 작업 지시서

## 목적
기존 DSR 대시보드에 "운송비" 시트(탭)를 추가한다. DSR(주문/출고 데이터)을 업로드하면
① 코드별 예상 배송비, ② 구간 경계에 걸린 오더 탐지, ③ 지점별 배송 빈도,
④ LY(2025) 대비 개선 현황을 자동 산출한다.
출력 형식은 기존 DSR 대시보드 컨벤션을 따른다: 오프라인 단일 HTML, columnar JSON 임베드, vanilla SVG 차트, 외부 의존성 없음.

## 함께 제공되는 기준 데이터 (3개 CSV, utf-8-sig)
1. `기준데이터_코드통합마스터.csv` — 동일 배송지 확정 75개 코드 → 통합그룹 (KCTC 통합정산 대상)
2. `기준데이터_코드권역매핑.csv` — On-Trade 전체 1,353개 배송처코드 → 배송처명·통합도매장·배송권역·누적배송료
3. `기준데이터_LY베이스라인.csv` — 연도(2025~2026.07)×월×권역: 배송건·박스·배송료·소량건·걸침건·HL
   ※ 2026.01~07 행도 포함되어 있으므로 YTD 비교에 그대로 사용 가능

### 규칙 (반드시 준수)
- **구간은 오더 단위가 아니라 "배송처(통합그룹)×배송일 합산 박스" 기준**으로 판정한다.
  같은 코드(또는 같은 통합그룹)의 동일자 오더는 합산 후 구간을 정한다.
- 배송료 = 요율(권역, 합산박스 구간) × 박스수.
- 코드통합마스터에 있는 코드는 **통합그룹 단위로 합산**해 구간을 판정한다 (KCTC 통합정산 확정분).
- On 제외 코드(집계에서 무시): 34122, 34137(중부한남체인), 33988, 85326(디오니엘앤비) — Off 재분류 확정.
- 제주권은 단일요율이므로 구간 알림 대상에서 제외한다.

## DSR 입력 매핑
DSR 업로드 파일에서 최소 필요 필드: **배송처코드(또는 거래처코드), 주문/출고일자, 박스수량**.
지점(지점장/FLM) 필드가 있으면 지점별 집계에 사용하고, 없으면 권역을 지점 대용으로 사용한다.
코드가 코드권역매핑.csv에 없는 경우 "신규/미매핑" 버킷으로 분리해 시트 하단에 표시한다 (오류로 중단하지 말 것).
박스수량이 아닌 낱개/HL 단위가 감지되면(수량 분포로 판단) 사용자에게 단위 확인을 요청한다.

## 시트 구성 (4개 섹션)

### A. 코드별 예상 배송비
- 업로드된 기간의 배송건(코드×일자, 통합그룹 적용) 단위로 예상 배송료 산출.
- 테이블: 통합도매장 | 권역 | 배송건수 | 총박스 | 예상 배송료 | 박스당 단가 | 적용 구간 분포.
- 정렬: 예상 배송료 내림차순, 상위 30 + 검색.

### B. 구간 걸침 오더 알림 (핵심 기능)
- 배송건 합산박스가 다음 범위면 플래그:
  - `4~5박스` → MOQ 후보 (6박스 시 구간 변경)
  - `9~10박스` → +1~2박스로 11~20 구간 진입
  - `19~20박스` → +1~2박스로 21~60 구간 진입
  - `55~60박스` → +1~6박스로 Over 60 진입 (범위 내 상한 근접일수록 우선)
- 각 알림 행에 표시: 도매장 | 권역 | 일자 | 현재 박스 | 추가 필요 박스 | 현재 요율 → 변경 요율 | **박스당 절감액 × 박스 = 예상 절감액**.
- 절감액 = (현재구간요율 − 차상위구간요율) × 현재 박스수 (물량 추가분 매출 효과는 별도 표기하지 않음).
- 상단 요약 카드: 걸침 오더 건수 / 전량 상향 시 절감액 / 권역별 분포.
- 소량(1~5박스) 알림에는 주석 고정 표기: "신규 거래처·시즈널 물량은 선별 적용" (일괄 제한 아님).

### C. 지점별 배송 빈도
- 통합도매장×주(ISO week) 단위 배송일수 집계.
- 주 4회 이상 배송 도매장 리스트 (과다빈도 협의 대상 — 주 3회는 창고 공간 제약상 정상으로 간주, 플래그 금지).
- 지점(또는 권역)별: 배송건수, 소량건 비중, 주4회+ 도매장 수.

### D. LY 비교 및 개선 현황
- LY베이스라인.csv의 동월·동권역 값과 비교: 배송료, 배송건, 박스당 단가, 소량건 비중, 걸침건수.
- 개선 지표(작을수록 좋음): 소량건 비중, 걸침건 방치율, 주4회+ 도매장 수.
- 권역 토글(전체/수도권/충청/전라/경상/강원/제주)은 기존 운송비 대시보드와 동일한 칩 UI.
- 코멘트 자동 생성 시 기준: 소량화는 수도권·강원 집중 이슈, 충청·전라는 물량 이탈 이슈.

## 수용 기준 (완료 전 자가 점검)
1. 동일 통합그룹의 동일자 오더가 합산되어 하나의 구간으로 판정되는가 (예: 원천 3코드).
2. 제외 코드 4개가 어떤 집계에도 포함되지 않는가.
3. 걸침 알림의 절감액이 요율표와 일치하는가 (수기 검증 예: 수도권 20박스 = 820×20=16,400 → 21박스 시 750×21=15,750).
4. LY 비교가 동월·동권역 기준으로 매칭되는가 (연간 합계와 혼동 금지).
5. 미매핑 코드가 있어도 시트가 정상 렌더링되는가.
